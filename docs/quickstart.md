# A Cow or Chicken: quick start

Owner: John (card T37). One printed page for someone who has never played.
This repo is public: the card never holds a link or an address.

You need: a Windows PC, a mouse, and the link Gabe texted you.

## 1. Install (once)

1. Open the link Gabe texted you.
2. Open the folder named Latest.
3. Download the file whose name ends in "windows.zip".
4. Open your Downloads folder.
5. Right-click the zip file and click "Extract All...".
6. Click "Extract".
7. Double-click "ACowOrChicken" in the folder that opens.
8. If Windows says "Windows protected your PC", click "More info".
9. Then click "Run anyway".
10. If Windows asks about network access, click "Allow".
11. On the screen "Your profile", type your first name in the "Name" box (12 letters at most).
12. Click a color square.
13. Click "Save".

You now see "A Cow or Chicken" with "Version" and a number under it.

## 2. Join

1. Click "Play".
2. On "Pick your hero", click one of the four heroes.
3. On "Join a game", look at the "Server address" box.
4. If the box is empty, type the address Gabe sent.
5. Click "Join".

If you see "Update the game from the Drive folder": close the game, then do part 1 again from step 1.
If you see any other message: tell Gabe the words on the screen.

## 3. Play

- Move: W, A, S, D (or the arrow keys).
- Aim: move the mouse.
- Shoot: left mouse button.
- Special move: Q. The Q box says "READY" when you can use it.
- Your team: the screen says "You are on Blue" or "You are on Orange".
- If you are knocked out: wait. The screen says "Back in" and counts down.
- The match ends with "Blue wins!", "Orange wins!" or "Draw".

To make everything bigger: on the first screen click "Settings", then change "UI scale".
